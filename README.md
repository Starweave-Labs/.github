## 如何维护

在独立分支中修改介绍或品牌资源，提交 PR 后通过评审合并。修改时注意：

1. 组织是伙伴共创品牌，不绑定某个个人，也不虚构团队规模或已有项目。
2. 探索方向与已经发布的作品分开陈述。
3. 项目链接、归属、版本与许可，以相应项目的实际状态为准。
4. ZUVI 暂未迁入组织；不要提前改写其仓库、文档、安装或发布地址。
5. 官网链接与品牌资源保持可访问；不填写未确认的联系方式。
